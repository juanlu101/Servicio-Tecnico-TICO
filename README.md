# Servicio Técnico TICO — Partes de avería

Web estática con los 10 partes de avería de la actividad. Índice (archivador) + ficha individual de cada parte.

- Las pruebas y la pista se entregan en la propia web: el profesor las autoriza con su clave.
  Los resultados van cifrados dentro del HTML y solo se pueden leer con esa clave.
- 5 créditos por caso (1 por prueba). Una sola pista por sesión (3 créditos), válida en cualquier parte.
- El archivador muestra los créditos sobrantes de cada parte. El botón «Nueva sesión · profesor» lo reinicia todo.
